# Учебный frontend-проект

## Описание

Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».

Тема проекта: многостраничный сайт интернет-магазина или каталога услуг.

## Структура проекта

- `index.html` — главная страница;
- `catalog.html` — каталог товаров;
- `product.html` — карточка товара с характеристиками;
- `order.html` — страница оформления заявки;
- `contacts.html` — контактная информация;
- `css/style.css` — файл стилей;
- `js/main.js` — файл JavaScript;
- `images/` — папка для изображений;
- `README.md` — описание проекта;
- `.gitignore` — список файлов, исключённых из Git.

## Дополнительные элементы

- `sitemap.xml` — простая карта сайта;
- Open Graph-теги — базовая разметка для отображения ссылок.

## Контрольная работа №3

Тема: «Адаптивная вёрстка и доступность многостраничного HTML/CSS-сайта».

Проект — многостраничный HTML/CSS-сайт интернет-магазина диванов (основа — КР №1, без Bootstrap). Страницы: `index.html`, `catalog.html`, `product.html`, `order.html`, `contacts.html`.

### Структура проекта

- `css/style.css` — базовые стили;
- `css/responsive.css` — адаптивные стили (подключается после `style.css`);
- `js/main.js` — модальное окно и валидация (из КР №1, не менялся, подключён на главной);
- `js/theme.js` — переключатель тёмной темы (подключён на всех страницах);
- `images/` — изображения (`sofa-N.jpg` 640px, `sofa-N-480.jpg`, `sofa-N-320.jpg`);
- `lighthouse/` — отчёт Lighthouse (Accessibility).

### Адаптивные решения

- добавлен `css/responsive.css`, подключён на всех 5 страницах после `style.css`;
- `viewport` присутствует на всех страницах;
- подход Mobile First, брейкпоинты 430px, 640px, 768px, 1024px, 1440px;
- навигация: на телефоне сетка в 2 колонки (Grid), от 640px — строка (Flexbox), от 768px — логотип слева, меню справа;
- hero-блок: размер заголовка и отступы растут с шириной, кнопка на всю ширину на телефоне;
- сетка карточек (Grid): 1 → 2 → 3 колонки;
- каталог: фильтр над товарами на телефоне и планшете, боковой sticky-фильтр от 1024px;
- страница товара: колонка на телефоне, картинка и описание в строку от 768px;
- таблица характеристик в `.table-wrapper` с `overflow-x: auto`;
- формы: одна колонка на телефоне, две от 768px; поля не ниже 44px, шрифт 16px;
- контакты: информация, форма обратной связи и карта; от 768px — две колонки;
- responsive images: `img { max-width: 100%; height: auto }`, `srcset` + `sizes` + `loading="lazy"`;
- модальное окно ограничено по высоте экрана и прокручивается внутри;
- горизонтального скролла страницы нет (проверено на 360px на всех страницах).

### Lighthouse

Проверяются `index.html`, `catalog.html`, `order.html`, категория Accessibility.
Отчёты сохранены в папке `lighthouse/` (`accessibility-index.html`, `accessibility-catalog.html`, `accessibility-order.html`): Accessibility — 100/100 на всех трёх страницах.

- мобильное меню-«бургер» без JavaScript (скрытый чекбокс и `label`, класс `:checked`), доступно с клавиатуры;
- тёмная тема: автоматически по `prefers-color-scheme` и кнопка-переключатель (выбор хранится в `localStorage`);

## Контрольная работа №4

Тема: «JavaScript: интерактивность, DOM, события, формы и валидация».

Проект `kr4-js-shop` создан на основе КР №3 (`kr3-responsive-shop`) — адаптивного интернет-магазина диванов.

### Структура проекта

- `index.html`, `catalog.html`, `product.html`, `cart.html`, `order.html`, `contacts.html` — страницы;
- `css/style.css`, `css/responsive.css` — стили;
- `js/` — скрипты (описаны ниже);
- `images/` — изображения.

### JavaScript-файлы

- `theme.js` — переключатель тёмной темы (сохраняется в `localStorage`);
- `data.js` — массив `products` (12 товаров, у каждого массив `images`) и функция `formatPrice`;
- `catalog.js` — генерация карточек, поиск, фильтрация, сортировка, счётчик и пустое состояние;
- `cart.js` — корзина, расчёт суммы через `reduce`, промокод, страница `cart.html`;
- `order.js` — состав заказа на `order.html` (`?product=ID` — один диван из каталога, `?from=cart` — товары корзины);
- `validation.js` — валидация форм, вывод ошибок на страницу;
- `main.js` — общая инициализация (на каждой странице запускаются только нужные модули, есть проверки наличия элементов).

### Массив товаров

В `data.js` 12 товаров с единой структурой: `id`, `title`, `category` (`classic` / `scandi` / `modern`), `price` (число), `isAvailable`, а также `isHit`, `images` (список путей к фото), `description`. Значения `category` совпадают со значениями `<option>` в фильтре.

### Реализованные функции

- Поиск: событие `input`, регистронезависимый поиск подстроки в названии.
- Фильтрация: событие `change` у `<select id="category">`, сравнение `product.category` с выбранным значением.
- Сортировка: по цене (возрастание/убывание) и названию; `sort()` применяется к новому массиву, полученному из `filter()`, поэтому исходный `products` не меняется.
- Счётчик «Найдено товаров» и пустое состояние с кнопкой «Сбросить фильтры».
- Маска телефона: при вводе `8` или `7` в начале подставляется `+7`, номер форматируется как `+7 (900) 000-00-00`.
- Валидация форм (`order.html`, форма обратной связи): имя, e-mail (регулярное выражение), телефон (формат `+7 (900) 000-00-00`), тема, сообщение, согласие. Ошибки выводятся под полями, общий статус — в блоке `.form-status`; `alert()` не используется. После успешной проверки появляется сообщение о подготовке заявки, форма очищается.

### Безопасный вывод данных

Все карточки и строки корзины создаются через `createElement`, текст записывается через `textContent`, классы добавляются через `classList`, элементы — через `append`. `innerHTML` не используется. Обработчики подключены через `addEventListener()`, inline-обработчиков в HTML нет.

### Самостоятельные доработки

- Корзина: добавление из каталога, изменение количества, удаление, очистка (делегирование событий на списке).
- Сумма корзины считается через `reduce`.
- Промокод `SOFA10` — скидка 10%.
- Корзина сохраняется в `localStorage`, счётчик товаров в шапке на всех страницах.
- Страница `product.html?id=N` строится из массива `products` (`initProductPage` в `catalog.js`): у каждого дивана свои данные и характеристики.
- Кнопки «В корзину» есть на главной, в каталоге и на странице товара; после нажатия появляется сообщение «добавлен в корзину».
- Карусель фото (кнопки и точки) на странице товара, если у дивана несколько фото (Milan, Sunset, Cognac, Loft).
- Заявка содержит состав заказа: из корзины — все выбранные диваны с количеством и итогом (после отправки корзина очищается), из каталога или карточки товара («Заказать») — один диван.
- Бейдж «Хит» и статус наличия у карточек; недоступные товары нельзя добавить в корзину.
- Расширенное пустое состояние каталога и очистка формы после отправки, сообщения об ошибках с `role="alert"`.

Как проверить: открыть `catalog.html`, ввести `nord`, выбрать категорию и сортировку, добавить товары в корзину, перейти в `cart.html` и ввести промокод `SOFA10`; на `order.html` отправить пустую форму, затем заполнить корректно.

### Запуск

Корзина использует `localStorage`, поэтому сайт нужно запускать через локальный сервер, а не открывать файл напрямую:

```bash
cd kr4-js-shop
python3 -m http.server 8000
```

Затем открыть `http://localhost:8000`.
